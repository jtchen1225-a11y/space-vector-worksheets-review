# L05　1.2.2 空間中的平面與空間向量（複習課）

> 課型：**複習課**｜工作紙 1.2.2 複習簡報（共 8 份）｜教材範圍：1.2.2 空間中的平面與空間向量。工作紙丙、戊兩關的題目全部收進第 3、4 階段（3-5、4-1、4-3、4-4），另加一頁跨情境題（4-5）；工作紙原設計 50 分鐘，這裏依複習課技能編成 40 分鐘，4-3、4-4 可擇一在課內做，另一頁留作功課。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：空間中的平面與空間向量
- 課時：40分鐘
- 課型：複習課
- 核心學習目標：不看筆記，能求平面的法向量，用方向向量與法向量判斷線面、面面的位置關係，並用三垂線定理證明線線垂直
- 先備知識：1.2.2 新課與工作紙練習；1.2.1 方向向量
- 教學重點：平面 ↔ 法向量；四種位置關係與兩個向量的平行、垂直對應
- 學習難點：v⊥n 當成線面垂直；三垂線定理用在不在平面內的直線；法向量取成零向量
- 本節刻意不教：用法向量求角與距離（1.2.3–1.2.5）

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 2-1 抓錯偵探：定理用對了嗎？

- 題目：斜線 \(PC\) 在平面 \(\alpha\) 的射影是 \(AC\)。直線 \(m\) 不在 \(\alpha\) 內，\(m\perp AC\)。
- 錯誤示例：\(m\) 垂直斜線的射影 \(AC\) → 由三垂線定理，\(m\perp PC\)（錯在第 2 步）
- 可能原因：概念錯誤：三垂線定理要求那條直線在平面內。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(m\) 不在 \(\alpha\) 內，不能用三垂線定理
- 修正後練習：斜坡過 \((4,0,0)\)、\((0,4,0)\)、\((0,0,2)\)。求斜坡的一個法向量

### 2-2 再抓一次：這是法向量嗎？

- 題目：求法向量：\(-x+2y=0\)，\(-x+2z=0\)。
- 錯誤示例：取 \(x=0\)，得 \(y=0\)，\(z=0\) → 法向量是 \((0,0,0)\)（錯在第 1 步）
- 可能原因：粗心失誤：零向量不能作法向量。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：改取 \(x=2\)，得 \((2,1,1)\)
- 修正後練習：斜坡過 \((4,0,0)\)、\((0,4,0)\)、\((0,0,2)\)。求斜坡的一個法向量

## E. 出口題及評估

- 出口題：平面 \(\alpha\) 過 \(A(2,0,0)\)，\(B(0,1,0)\)，\(C(0,0,1)\)；直線 \(l\) 的方向向量是 \((1,2,2)\)。求 \(\alpha\) 的一個法向量，並判斷 \(l\) 與 \(\alpha\) 的關係。
- 參考答案：法向量 \((1,2,2)\)；方向向量與法向量平行，\(l\perp\alpha\)
- 時間：2～3 分鐘，獨立完成。

### 2. 螺旋深化路徑

- 學生已經理解：已分別練過求法向量和各種位置關係的判斷。
- 本次新增的理解：把四種關係放在一張表：線面垂直、線面平行、面面平行、面面垂直，都只是 v、n 或兩個 n 的平行或垂直；並記住數量積為 0 時還要檢查一點。
- 之後會延伸到：1.2.3 起，同一個法向量用來求線面角、面面角和點面距離。

### 3. 分層學習任務
