# L04　1.2.1 空間中的點、直線與空間向量（複習課）

> 課型：**複習課**｜工作紙 1.2.1 複習簡報（共 8 份）｜教材範圍：1.2.1 空間中的點、直線與空間向量。工作紙丙、戊兩關的題目全部收進第 3、4 階段（3-5、4-1、4-3、4-4），另加一頁跨情境題（4-5）；工作紙原設計 50 分鐘，這裏依複習課技能編成 40 分鐘，4-3、4-4 可擇一在課內做，另一頁留作功課。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：空間中的點、直線與空間向量
- 課時：40分鐘
- 課型：複習課
- 核心學習目標：不看筆記，能用方向向量判斷兩直線的位置關係，求兩直線所成的角，並求異面直線的公垂線段長
- 先備知識：1.2.1 新課與工作紙練習；1.1.3 坐標運算
- 教學重點：直線 ↔ 方向向量；位置關係與角都由方向向量決定
- 學習難點：方向向量平行時忽略重合；不平行就說相交；所成角的餘弦沒有取絕對值
- 本節刻意不教：平面的法向量（1.2.2）

### 第 1 階段　0–5 分鐘　複習目標＋概念提取（簡報：熱身快問：你還記得多少？；螺旋：概念提取）

- 學生活動：不看筆記作答。
- 教學資源：互動簡報 1-1 今天的目標、1-2 快問快答、1-3 快問二：角的範圍、1-4 快問三：異面；學習單（handout.html）。
- 理解檢查：\(A(1,0,2)\)，\(B(3,1,0)\)，直線 \(AB\) 的一個方向向量是？；兩條直線所成的角，最大是多少？；不同在任何一個平面內的兩條直線，叫做？
- 可能困難（預期情況）：概念錯誤：把坐標相加；概念錯誤：這是點 \(A\) 的坐標；概念錯誤：這是向量夾角的最大值

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 2-1 抓錯偵探：真的平行嗎？

- 題目：\(l_{1}\) 過原點，方向 \((1,1,0)\)；\(l_{2}\) 過 \((2,2,0)\)，方向 \((2,2,0)\)。兩直線的關係？
- 錯誤示例：兩個方向向量成倍數 → 所以兩直線平行（錯在第 2 步）
- 可能原因：概念錯誤：\((2,2,0)\) 在 \(l_{1}\) 上，兩直線其實重合。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：方向向量平行後，還要檢查一點：這裏是重合
- 修正後練習：馬路過原點，天橋過 \((0,0,5)\)，方向同上。兩者的公垂線段有多長？

### 2-2 再抓一次：不平行就相交？

- 題目：\(l_{1}\) 過原點，方向 \((1,0,0)\)；\(l_{2}\) 過 \((0,0,1)\)，方向 \((0,1,0)\)。兩直線的關係？
- 錯誤示例：方向向量不成倍數，所以不平行 → 不平行，所以相交（錯在第 2 步）
- 可能原因：概念錯誤：空間中不平行的兩條直線還可能異面。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：兩直線沒有公共點，是異面直線
- 修正後練習：馬路過原點，天橋過 \((0,0,5)\)，方向同上。兩者的公垂線段有多長？

## E. 出口題及評估

- 出口題：棱長 2 的正方體（\(D\) 為原點），\(E\)、\(F\) 是 \(AB\)、\(CC_{1}\) 的中點。求 \(EF\) 與 \(A_{1}D\) 所成角的餘弦。
- 參考答案：\(\overrightarrow{EF}=(-2,1,1)\)，\(\overrightarrow{A_1D}=(-2,0,-2)\)，餘弦是 \(\frac{\sqrt{3}}{6}\)
- 時間：2～3 分鐘，獨立完成。

| 結果 | 判準及下一節安排 |
|------|------|
| 已掌握 | 兩個向量正確，餘弦取正值並化簡 → 下一節複習 1.2.2 時直接做 C 層 |

### 2. 螺旋深化路徑

- 學生已經理解：已分別練過方向向量、所成的角和公垂線段。
- 本次新增的理解：看出一條直線由「一點＋方向向量」決定：平行、垂直、角只看方向向量；重合、相交、異面還要看點。
- 之後會延伸到：1.2.2 用法向量描述平面；1.2.3、1.2.4 把同一套做法用於線面角和面面角。

### 3. 分層學習任務

| 學生 | 任務層 | 支持方式 | 完成後 |
|------|------|------|------|
| 基礎薄弱 | A 層 | 提示階梯、附圖與第一步線索 | 嘗試 B 層 |
| 一般 | B 層 | 必要時看提示 | 嘗試 C 層 |
| 能力較高 | C 層 | 少提示，要求解釋或比較 | 自編變式題 |

分層指任務與支持不同，不是固定學生標籤；學生可依表現隨時換層。

### 5. 學習證據追蹤

- 出口題（當堂）：見 E 節。
