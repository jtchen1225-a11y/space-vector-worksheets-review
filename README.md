# 空間向量工作紙 1.1.1–1.2.5：投影複習簡報

把 8 份工作紙（1.1.1 空間向量及其運算 至 1.2.5 空間中的距離）依「複習課」技能（math-lesson-review）編成 8 節 40 分鐘的投影複習簡報。每節包含互動簡報、列印紙本與教案。

這個 Repo 是獨立的複習簡報，與練習課網頁版（space-vector-worksheets-web）和全章授課（space-vector-geometry-lessons）分開：課型、頁面流程、快問、抓錯、互動圖、跨情境題、出口題和延遲檢測題都是另外編寫的；只有工作紙丙、戊兩關的題目本身相同，因為兩者都由同一批工作紙轉化而來。

- 入口：`docs/index.html`（GitHub Pages 網址見 Repo 右側 About）
- 教案總覽：`docs/chapter-plan.html`
- 各節：`docs/lessons/Lnn/`（`index.html` 簡報、`handout.html` 紙本、`lesson-plan.html` 教案）
- 原工作紙（學生版 PDF）：`docs/worksheets/`

整個 `docs` 資料夾下載後可以離線開啟（雙擊 `index.html`），不連網、不用 CDN。

## 每節的流程（知識整合螺旋）

| 階段 | 時間 | 內容 | 工作紙來源 |
|------|------|------|------|
| 1 熱身快問（概念提取） | 0–5 | 不看筆記的三道快問 | 甲 熱身 |
| 2 陷阱大搜查（錯誤診斷） | 5–12 | 兩個錯誤解法、兩道「誰是對的」 | 教師答案的常見錯誤 |
| 3 把概念串起來（知識連結） | 12–22 | 概念連連看、可拖滑桿的互動圖、兩道快問、升級挑戰 | 乙、丁 跟著做；丙 第一關 |
| 4 走出課本（跨情境遷移） | 22–35 | 計時闖關、其餘工作紙題目、生活情境題 | 戊 第二關；丙、戊 各層第 2 題 |
| 5 最後一關（學習證據） | 35–40 | 出口題、自評、核心知識小結 | 己（同概念、新題目） |

工作紙丙、戊兩關的題目都收在 3-5、4-1、4-3、4-4；少數已改成抓錯或快問的題目，原位換上一道標明「另一題」的同類題。

## 製作方式

內容來源是 `source/lessons/Lnn.js`，教案由同一份資料產生。每節的 `@assert` 區塊會驗算答案，算錯時建置失敗。

```powershell
python source\autofit.py        # 建置並依實測拆頁（放不下就拆頁，不縮字）
python source\verify_all.py     # 發布前總檢查：重建、合成 docs、五層驗證、點擊測試、全狀態版面檢查
```

建置需要同層的 `..\repos\math-lesson-review`（複習課技能）和 `..\vector-worksheets`（工作紙 PDF）。

## 未驗證的項目

- 學生表現皆為「預期情況」，尚未經真實課堂驗證。
- 列印效果、投影機實機效果尚未人工確認。
- 數學內容已由程式驗算主要答案，仍建議教師上課前再看一次。
